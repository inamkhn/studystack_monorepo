## Brand & Style

This design system embodies a forward-looking union between disciplined scholarship and cognitive AI intelligence. Tailored for ambitious autodidacts, graduate researchers, and technical professionals, the visual aesthetic conveys depth, structural rigor, and intellectual clarity.

The aesthetic philosophy balances **Atmospheric Tech Glassmorphism** with **Neo-Academic Precision**:
- **Structured Foundations:** Underlying fine-mesh technical grids, disciplined line structures, and crisp micro-borders anchor the interface in logic and academic rigor.
- **Luminous Overlays:** Deep midnight and slate surfaces interact with crystalline, frosted glass containers that reflect glowing focal highlights, signaling computational intelligence.
- **Editorial Sharpness:** High-contrast type interplay elevates the product from a utilitarian study app to an authoritative intellectual operating system.

## Colors

The palette establishes a midnight study environment that minimizes optical fatigue while focusing attention on synthetic intelligence and conceptual mastery.

- **Primary (`#6366F1` - Electric Indigo):** The core active intelligence token. Denotes primary action pathways, active generative states, cognitive node links, and prominent callouts.
- **Secondary (`#10B981` - Kinetic Emerald):** The symbol of cognitive mastery, retention milestones, and validated accuracy. Deployed across success states, retention streak graphs, and verified recall data points.
- **Tertiary (`#38BDF8` - Cyan Flux):** A supplementary data highlight for real-time processing indicators, algorithmic confidence scores, and auxiliary interactive controls.
- **Neutral (`#0B0F19` - Deep Slate Obsidian):** Deep abyss tone serving as the foundational canvas. Paired with elevated slate containers (`#111827`, `#1E293B`) and pristine high-contrast foreground typography (`#F8FAFC`, `#E2E8F0`, `#94A3B8`).

## Typography

The typographic hierarchy implements three distinct roles:
1. **Plus Jakarta Sans (Display & Headlines):** Modern, geometric, and authoritative. Tight negative tracking lends momentum and architectural structure to high-level headers.
2. **Inter (Body & Narrative):** Neutral, hyper-legible, and ergonomically balanced for dense research summaries, thesis arguments, and flashcard recall texts.
3. **JetBrains Mono (Technical Metadata & Mastery Metrics):** Monospaced precision for algorithmic telemetry, cognitive load ratings, study timers, and key-command shortcuts.

Use uppercase transforms exclusively on `label-sm` with widened letter-spacing to delineate metadata headers from fluid text.

## Layout & Spacing

The layout structure relies on a dynamic 12-column grid anchored on a maximum canvas width of `1280px`.

- **Desktop (>= 1024px):** 12 columns with `1.5rem` gutters and `3rem` exterior margin boundaries. Asymmetrical arrangements pair interactive workspace previews with high-density feature documentation.
- **Tablet (768px - 1023px):** 8 columns with `1.5rem` gutters and `2rem` margins. Interactive sandbox components collapse beneath primary narrative copy.
- **Mobile (< 768px):** 4 columns with `1rem` gutters and `1.25rem` margins. Multicolumn dashboards stack into single-column vertical flows with horizonal swipe-rail controls for dense telemetry decks.

Spacing between nested card elements must follow an 8pt mathematical rhythm, ensuring mathematical harmony across complex information boards.

## Elevation & Depth

Visual hierarchy uses frosted translucent strata, hairline borders, and targeted luminescent lighting rather than heavy drop shadows:

- **Level 0 (Canvas):** Pure `#0B0F19` background punctuated by an ambient radial gradient (`#6366F1`, 12% opacity, 600px blur) centered behind high-priority hero elements. A 24px x 24px subtle geometric grid drawn with `rgba(255, 255, 255, 0.03)` provides structural texture.
- **Level 1 (Subsurface Cards & Canvas Shelves):** Background filled with `rgba(17, 24, 39, 0.7)` supported by a `backdrop-filter: blur(12px)`. Enclosed with a 1px border of `rgba(255, 255, 255, 0.08)`.
- **Level 2 (Interactive Floating Modules & Modals):** Background of `rgba(30, 41, 59, 0.65)` layered with `backdrop-filter: blur(20px)`. Outer border highlighted with `rgba(99, 102, 241, 0.25)` and a directional top highlight: `inset 0 1px 0 0 rgba(255, 255, 255, 0.15)`. Soft atmospheric shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.6)`.
- **Level 3 (Focused & Active Cognitive Nodes):** Glass container surrounded by a continuous dual-glow aura: `box-shadow: 0 0 25px -4px rgba(99, 102, 241, 0.4), inset 0 0 12px 0 rgba(99, 102, 241, 0.15)`.

## Shapes

The interface embraces a structured, modern curvature (`roundedness: 2`):
- **Base Components (Inputs, Buttons, Badges):** `0.5rem` (8px) for crisp interaction targets that retain architectural firmness.
- **Standard Cards & Learning Modules:** `1rem` (16px) balance soft tactile approachability with disciplined spatial composition.
- **Hero Highlights & Interactive Display Frames:** `1.5rem` (24px) to frame complex dashboard previews cleanly.
- **Indicator Nodes & Interactive Chips:** True pill (`9999px`) roundedness to distinguish transient status indicators from structural containers.

## Components

### Buttons
- **Primary Action:** Solid `#6366F1` background with white high-contrast text (`JetBrains Mono`, `label-md`). Finished with an inset upper highlight of `rgba(255, 255, 255, 0.25)` and an ambient indigo glow on hover (`0 0 20px rgba(99, 102, 241, 0.45)`).
- **Secondary (Glass):** Frosted glass surface (`rgba(255, 255, 255, 0.05)`), 1px border (`rgba(255, 255, 255, 0.15)`), shifting to `rgba(255, 255, 255, 0.1)` on hover with crisp `#F8FAFC` label text.
- **Tertiary Subtle:** Ghost styling with no border; text renders in `#94A3B8`, transitioning to `#6366F1` with an underline slide on hover.

### Chips & Badges
- **Status / Model Badge:** Monospace pill (`label-sm`) with a 1px border and a pulsing live status dot (`#10B981` or `#6366F1`). Interior fill uses `rgba(99, 102, 241, 0.08)`.
- **Topic Filter Chip:** `rounded-lg` container with low-contrast border. Active state shifts background to `#6366F1` with an emerald check indicator.

### Flashcard & Demo Modules
- Multi-layered card featuring high-density typography, micro-grid card headers displaying deck statistics via `JetBrains Mono`, and keyboard shortcut hints (`⌘ + Space` or `1-4` recall triggers) bounded within crisp kbd-style badges.

### Input Fields
- Dark translucent slate fill (`rgba(15, 23, 42, 0.6)`) with inset shadow. Default border is `rgba(255, 255, 255, 0.1)`. Focus state illuminates the border with a sharp `#6366F1` line and a 3px diffused outer halo (`rgba(99, 102, 241, 0.2)`).

### Mastery Progress & Metrics
- Linear and radial telemetry meters featuring background tracks in `rgba(255, 255, 255, 0.06)` and active fills in neon `#10B981`, paired with cyan gradient feathering to emphasize mastery acceleration.
